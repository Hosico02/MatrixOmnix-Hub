MatrixOmnix Hub

d2p productization 运行的 PM + mentor 操作台。

MatrixOmnix Hub 是一个本地自托管的小型多项目中心。 d2p 实例在每次 productization 运行时把事件推送上来, Hub 聚合数据、识别规则漂移、把待人决策的事项挑出来, 通过中文化的 Vue 仪表板交给人审批。 所有标准修改都需要人点 ✓ 才生效。

Hub 自己不修改任何项目代码 —— 它只观察、打分、汇报、学习。

它解决的问题

  • 🔭多机集中观察 —— 不同机器、不同项目的 d2p 实例都汇报到这里, 一处看完所有运行状态。
  • 🧠跨 run 学习 —— 5 条 SQL 规则 + 每周 Opus 归纳, 识别 d2p 标准里反复缺失或失效的检查项。
  • 📥人机闭环 —— 系统提议规则改动,但只有你接受后才生效; 所有修改可审计、可回滚。
  • 🌐对 d2p 完全 fail-safe —— Hub 挂了 d2p 照常运行, verifier 用本地缓存的 standards 兜底。

快速开始

启动 Hub

git clone https://github.com/Hosico02/demo2project.git
cd demo2project
pnpm install
pnpm hub:build

# 一次性: 初始化 DB,生成第一个 d2p 实例 token
HUB_DB_PATH=~/.matrixomnix/hub.db pnpm hub:seed

# 启动 Hub
HUB_ADMIN_TOKEN=$(openssl rand -hex 16) pnpm hub:start
open http://127.0.0.1:3030

在 d2p 那边接入

export HUB_URL=http://127.0.0.1:3030
export HUB_TOKEN=<hub:seed 打印的那个 token>

python run.py   # d2p 自动上报到 Hub

仪表板三视图

运行 (主页) —— 哪些项目在跑、哪些刚完成、本周 d2p 的战绩。

规则 —— 每种 archetype 当前在用的检查规则、改动历史、可一键回滚。

待办 —— 学习器提出的规则改动建议,等你 ✓ 接受 / ✗ 不要 / ✎ 改下措辞。
